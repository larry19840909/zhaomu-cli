# 获取海外服务器加速信息

## 简要描述

获取用户某个海外服务器加速信息

## 请求URL

`https://api.zhaomu.com/accelerator/:id`

## 请求方式

GET

## 路径变量

| 变量名 | 示例值 | 必选 | 类型 | 说明 |
|--------|--------|--------|--------|--------|
| id | 1 | 是 | string | 加速器编号。参见 [获取海外服务器加速列表](获取海外服务器加速列表.md) 查询 |

## Header

| 字段名 | 示例值 | 必选 | 类型 | 说明 |
|--------|--------|--------|--------|--------|
| Authorization | Bearer <apikey> | 是 | string | API密钥 |

## 成功返回示例

```json
复制{
  "id": 1,
  "type": "基础版",
  "domain": "123.123.123.123_30896.ipssh.net",
  "region": "cn-sh2",
  "ip": "123.123.123.123",
  "port": 8888,
  "area": "香港",
  "startTime": "2026-01-01 15:12:01",
  "endTime": "2026-04-01 15:12:01",
  "renewPrice": 30,
  "paymentCycle": 1
}
```

## 成功返回示例的参数说明

| 参数名 | 类型 | 说明 |
|--------|--------|--------|
| id | int | 加速器编号（实例 ID） |
| type | string | 产品类型。实测值：基础版、专业版 |
| domain | string | 加速域名 |
| region | string | 入口区域。cn-bj2=北京, cn-sh2=上海, cn-gd=广州 |
| ip | string | 被加速服务器 IP 地址 |
| port | int | 应用端口。不支持 80/443 |
| area | string | 服务器靠近区域（中文）。实测值：香港、台湾、东京、洛杉矶、新加坡、法兰克福、华盛顿、伦敦 |
| startTime | string | 开通时间 |
| endTime | string | 到期时间 |
| renewPrice | number | 续费价格，单位元 |
| paymentCycle | int | 付款周期。1=月付, 2=季付, 3=半年付, 4=年付 |

## 备注

入口区域cn-bj2：北京cn-sh2：上海cn-gd：广州

付款周期1：月付2：季付3：半年付4：年付

## 实测返回示例

```json
{
  "id": 3928,
  "ip": "98.98.115.246",
  "port": 19855,
  "type": "专业版",
  "area": "台湾",
  "region": "cn-sh2",
  "domain": "98.98.115.246_30896.ipssh.net",
  "startTime": "2026-07-07 16:01:12",
  "endTime": "2026-08-07 16:01:12",
  "renewPrice": 80,
  "paymentCycle": 1
}
```

## 返回字段说明

| 参数名| 类型 | 说明 |
|--------|--------|--------|
| id | int | 加速器自然主键|
| ip | string | 被加速服务器 IP |
| port | int | 加速应用端口 |
| type | string | 产品类型名称（"基础版"或"专业版"） |
| area | string | 服务器靠近区域（中文）|
| region | string | 入口区域标识（cn-bj2/cn-sh2/cn-gd） |
| domain | string | 加速域名 |
| startTime | string | 开通时间（YYYY-MM-DD HH:mm:ss） |
| endTime | string | 到期时间（YYYY-MM-DD HH:mm:ss） |
| renewPrice | int | 续费价格（元）|

## 备注

入口区域
cn-bj2：北京
cn-sh2：上海
cn-gd：广州

付款周期
1：月付
2：季付
3：半年付
4：年
