# 订购海外服务器加速

## 简要描述

订购海外服务器加速，实时开通

## 请求URL

`https://api.zhaomu.com/accelerator/order`

## 请求方式

POST

## Header

| 字段名 | 示例值 | 必选 | 类型 | 说明 |
|--------|--------|--------|--------|--------|
| Authorization | Bearer <apikey> | 是 | string | API密钥 |

## 请求Body参数

| 参数名 | 示例值 | 必选 | 类型 | 说明 |
|--------|--------|--------|--------|--------|
| productId | 1 | 是 | int | 产品编号 |
| region |  | 是 | string | 入口区域 |
| ip |  | 是 | string | 无 |
| port |  | 是 | int | 不支持80或443端口 |
| area |  | 是 | string | 服务器靠近区域 |
| paymentCycle | 1 | 是 | int | 付款周期 |

## 备注

产品编号1：基础版，2：专业版

入口区域cn-bj2：北京cn-sh2：上海cn-gd：广州

付款周期1：月付2：季付3：半年付4：年付

服务器靠近区域香港、新加坡、东京、洛杉矶、华盛顿、法兰克福、拉各斯
