# 获取海外服务器加速列表

## 简要描述

获取用户全部海外服务器加速列表

## 请求URL

`https://api.zhaomu.com/accelerator`

## 请求方式

GET

## Header

| 字段名 | 示例值 | 必选 | 类型 | 说明 |
|--------|--------|--------|--------|--------|
| Authorization | Bearer <apikey> | 是 | string | API密钥 |

## 成功返回示例

```json
复制[{
  "id": 1,
  "type": "基础版",
  "domain": "123.123.123.123_30896.ipssh.net",
  "region": "cn-sh2",
  "ip": "123.123.123.123",
  "port": 8888,
  "area": "香港",
  "startTime": "2026-01-01 15:12:01",
  "endTime": "2026-04-01 15:12:01",
  "renewPrice": 30,
  "paymentCycle": 1
}]
```

## 成功返回示例的参数说明

| 参数名 | 类型 | 说明 |
|--------|--------|--------|
| id | int | 海外服务器加速编号 |
| type | string | 类型 |
| domain | int | 加速域名 |
| region | string | 入口区域 |
| ip | string | 服务器IP |
| port | string | 应用端口 |
| area | string | 服务器靠近区域 |
| startTime | string | 开通时间 |
| endTime | string | 到期时间 |
| renewPrice | string | 续费价格 |
| paymentCycle | string | 付款周期 |

## 备注

入口区域cn-bj2：北京cn-sh2：上海cn-gd：广州

付款周期1：月付2：季付3：半年付4：年付
