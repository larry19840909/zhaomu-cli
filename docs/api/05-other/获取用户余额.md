# 获取用户余额

## 简要描述

获取用户余额

## 请求URL

`https://api.zhaomu.com/other/balance`

## 请求方式

GET

## Header

| 字段名 | 示例值 | 必选 | 类型 | 说明 |
|--------|--------|--------|--------|--------|
| Authorization | Bearer <apikey> | 是 | string | API密钥 |

## 成功返回示例

```json
复制{
  "balance": 1000
}
```

## 成功返回示例的参数说明

| 参数名 | 类型 | 说明 |
|--------|--------|--------|
| balance | number | 用户余额 |

## 备注

无

## 实测返回示例

```json
{
  "balance": 0.8
}
```

## 实测字段说明

| 字段 | 类型 | 说明 |
|------|------|------|
| balance | float | 账户余额（单位：元） |
