# 变更云服务器

## 简要描述

变更某台云服务器的配置

## 请求URL

`https://api.zhaomu.com/cloud/upgrade/:id`

## 请求方式

POST

## 路径变量

| 变量名 | 示例值 | 必选 | 类型 | 说明 |
|--------|--------|--------|--------|--------|
| id | 21299 | 是 | int | 云服务器编号 |

## Header

| 字段名 | 示例值 | 必选 | 类型 | 说明 |
|--------|--------|--------|--------|--------|
| Authorization | Bearer <apikey> | 是 | string | API密钥 |

## 请求Body参数

| 参数名 | 示例值 | 必选 | 类型 | 说明 |
|--------|--------|--------|--------|--------|
| productId | 1 | 否 | int | 产品编号 |
| disk | 40 | 否 | int | 系统盘大小 |
| diskData | 20 | 否 | int | 数据盘大小 |
| bandwidth | 5 | 否 | string | 带宽 |

## 成功返回示例

```json
复制{
  "success": true,
  "message": "变更云服务器：155.138.139.237"
}
```

## 成功返回示例的参数说明

| 参数名 | 类型 | 说明 |
|--------|--------|--------|
| success | boolean | 成功/失败 |
| message | string | 返回信息 |

## 备注

无
