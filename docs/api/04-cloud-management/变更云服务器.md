# 变更云服务器

## 简要描述

变更某台云服务器的配置

## 请求URL

`https://api.zhaomu.com/cloud/upgrade/:id`

## 请求方式

POST

## 路径变量

| 变量名 | 示例值 | 必选 | 类型 | 说明 |
|--------|--------|--------|--------|--------|
| id | 21299 | 是 | int | 云服务器编号。参见 [获取云服务器列表](../03-cloud-lifecycle/获取云服务器列表.md) 查询 |

## Header

| 字段名 | 示例值 | 必选 | 类型 | 说明 |
|--------|--------|--------|--------|--------|
| Authorization | Bearer <apikey> | 是 | string | API密钥 |

## 请求Body参数

| 参数名 | 示例值 | 必选 | 类型 | 说明 |
|--------|--------|--------|--------|--------|
| productId | 1 | 否 | int | 目标产品编号。参见 [获取云服务器产品列表](../02-products/获取云服务器产品列表.md) |
| disk | 40 | 否 | int | 目标系统盘大小(GB) |
| diskData | 20 | 否 | int | 目标数据盘大小(GB) |
| bandwidth | 5 | 否 | int | 目标带宽(Mbps) |

## 成功返回示例

```json
复制{
  "success": true,
  "message": "变更云服务器：155.138.139.237"
}
```

## 成功返回示例的参数说明

| 参数名 | 类型 | 说明 |
|--------|--------|--------|
| success | boolean | 成功/失败 |
| message | string | 返回信息 |

## 备注

无
