# 续费云服务器

## 简要描述

续费某台云服务器

## 请求URL

`https://api.zhaomu.com/cloud/renew/:id`

## 请求方式

POST

## 路径变量

| 变量名 | 示例值 | 必选 | 类型 | 说明 |
|--------|--------|--------|--------|--------|
| id | 21299 | 是 | int | 云服务器编号。参见 [获取云服务器列表](../03-cloud-lifecycle/获取云服务器列表.md) 查询 |

## Header

| 字段名 | 示例值 | 必选 | 类型 | 说明 |
|--------|--------|--------|--------|--------|
| Authorization | Bearer <apikey> | 是 | string | API密钥 |

## 请求Body参数

| 参数名 | 示例值 | 必选 | 类型 | 说明 |
|--------|--------|--------|--------|--------|
| paymentCycle | 1 | 是 | int | 付款周期。1=月付, 2=季付, 3=半年付, 4=年付 |

## 成功返回示例

```json
复制{
  "success": true,
  "message": "续费云服务器：155.138.139.237，1个月"
}
```

## 成功返回示例的参数说明

| 参数名 | 类型 | 说明 |
|--------|--------|--------|
| success | boolean | 成功/失败 |
| message | string | 返回信息 |

## 备注

无
