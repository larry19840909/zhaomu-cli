# 重装云服务器

## 简要描述

重装某台云服务器

## 请求URL

`https://api.zhaomu.com/cloud/rebuild/:id`

## 请求方式

POST

## 路径变量

| 变量名 | 示例值 | 必选 | 类型 | 说明 |
|--------|--------|--------|--------|--------|
| id | 21299 | 是 | int | 云服务器编号。参见 [获取云服务器列表](../03-cloud-lifecycle/获取云服务器列表.md) 查询 |

## Header

| 字段名 | 示例值 | 必选 | 类型 | 说明 |
|--------|--------|--------|--------|--------|
| Authorization | Bearer <apikey> | 是 | string | API密钥 |

## 请求Body参数

| 参数名 | 示例值 | 必选 | 类型 | 说明 |
|--------|--------|--------|--------|--------|
| imageId | 13 | 是 | int | 镜像编号。参见 [获取重装云服务器的镜像](获取重装云服务器的镜像.md) 或 [获取订购云服务器的镜像](../03-cloud-lifecycle/获取订购云服务器的镜像.md) 中的实测镜像列表 |

## 成功返回示例

```json
复制{
  "success": true,
  "message": "重装系统命令发送成功，大约需要5分钟时间，Windows操作系统需要10分钟左右"
}
```

## 成功返回示例的参数说明

| 参数名 | 类型 | 说明 |
|--------|--------|--------|
| success | boolean | 成功/失败 |
| message | string | 返回信息 |

## 备注

无
