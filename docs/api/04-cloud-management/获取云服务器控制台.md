# 获取云服务器控制台

## 简要描述

获取某台云服务器的noVNC控制台信息

## 请求URL

`https://api.zhaomu.com/cloud/novnc/:id`

## 请求方式

GET

## 路径变量

| 变量名 | 示例值 | 必选 | 类型 | 说明 |
|--------|--------|--------|--------|--------|
| id |  | 是 | int | 云服务器编号 |

## Header

| 字段名 | 示例值 | 必选 | 类型 | 说明 |
|--------|--------|--------|--------|--------|
| Authorization | Bearer <apikey> | 是 | string | API密钥 |

## 成功返回示例

```json
复制{
  "success": true,
  "message": "http://www.mysuperdns.com/novnc/xxx"
}
```

## 成功返回示例的参数说明

| 参数名 | 类型 | 说明 |
|--------|--------|--------|
| success | boolean | 成功/失败 |
| message | string | 控制台URL |

## 备注

无
