# 销毁云服务器

## 简要描述

销毁某台云服务器

## 请求URL

`https://api.zhaomu.com/cloud/destroy/:id`

## 请求方式

DELETE

## 路径变量

| 变量名 | 示例值 | 必选 | 类型 | 说明 |
|--------|--------|--------|--------|--------|
| id | 21299 | 是 | int | 云服务器编号 |

## Header

| 字段名 | 示例值 | 必选 | 类型 | 说明 |
|--------|--------|--------|--------|--------|
| Authorization | Bearer <apikey> | 是 | string | API密钥 |

## 成功返回示例

```json
复制{
  "success": true,
  "message": "云服务器销毁成功"
}
```

## 成功返回示例的参数说明

| 参数名 | 类型 | 说明 |
|--------|--------|--------|
| success | boolean | 成功/失败 |
| message | string | 返回信息 |

## 备注

无
