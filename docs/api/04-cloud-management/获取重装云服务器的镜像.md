# 获取重装云服务器的镜像

## 简要描述

获取重装云服务器时，可选的镜像列表

## 请求URL

`https://api.zhaomu.com/image/cloud/:id`

## 请求方式

GET

## 路径变量

| 变量名 | 示例值 | 必选 | 类型 | 说明 |
|--------|--------|--------|--------|--------|
| id |  | 是 | int | 云服务器编号 |

## Header

| 字段名 | 示例值 | 必选 | 类型 | 说明 |
|--------|--------|--------|--------|--------|
| Authorization | Bearer <apikey> | 是 | string | API密钥 |

## 成功返回示例

```json
复制[{
  "id": 5,
  "name": "CentOS 7 64位",
  "type": "CentOS"
},{
  "id": 8,
  "name": "Ubuntu 18.04 64位",
  "type": "Ubuntu"
}]
```

## 成功返回示例的参数说明

| 参数名 | 类型 | 说明 |
|--------|--------|--------|
| id | int | 镜像编号 |
| name | string | 镜像名称 |
| type | string | 镜像类型 |

## 备注

无

## 实测镜像列表

**可重装镜像类型（实测）：**

| 类型 | 示例镜像 |
|------|---------|
| AlmaLinux | AlmaLinux 9 (ID:2809), AlmaLinux 8 (ID:2808) |
| Debian | Debian 13 (ID:4423), Debian 12 (ID:2812), Debian 11 (ID:1719) |
| Ubuntu | Ubuntu 24.04 (ID:3349), Ubuntu 22.04 (ID:2713), Ubuntu 20.04 (ID:842) |
