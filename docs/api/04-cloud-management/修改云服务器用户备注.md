# 修改云服务器用户备注

## 简要描述

修改某台云服务器的用户备注

## 请求URL

`https://api.zhaomu.com/cloud/note/:id`

## 请求方式

POST

## 路径变量

| 变量名 | 示例值 | 必选 | 类型 | 说明 |
|--------|--------|--------|--------|--------|
| id | 21299 | 是 | int | 云服务器编号 |

## Header

| 字段名 | 示例值 | 必选 | 类型 | 说明 |
|--------|--------|--------|--------|--------|
| Authorization | Bearer <apikey> | 是 | string | API密钥 |

## 请求Body参数

| 参数名 | 示例值 | 必选 | 类型 | 说明 |
|--------|--------|--------|--------|--------|
| note | 测试云服务器 | 是 | string | 用户备注 |

## 成功返回示例

```json
复制{
  "success": true,
  "message": "用户备注修改成功"
}
```

## 成功返回示例的参数说明

| 参数名 | 类型 | 说明 |
|--------|--------|--------|
| success | boolean | 成功/失败 |
| message | string | 返回信息 |

## 备注

无
