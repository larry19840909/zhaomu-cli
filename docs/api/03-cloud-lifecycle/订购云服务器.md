# 订购云服务器

## 简要描述

订购一台云服务器，执行后通过获取云服务器信息接口查询开通状态

## 请求URL

`https://api.zhaomu.com/cloud/order`

## 请求方式

POST

## Header

| 字段名 | 示例值 | 必选 | 类型 | 说明 |
|--------|--------|--------|--------|--------|
| Authorization | Bearer <apikey> | 是 | string | API密钥 |

## 请求Body参数

| 参数名 | 示例值 | 必选 | 类型 | 说明 |
|--------|--------|--------|--------|--------|
| productId | 91 | 是 | int | 产品编号。参见 [获取云服务器产品列表](../02-products/获取云服务器产品列表.md) |
| disk | 40 | 是 | int | 系统盘大小，单位 GB |
| diskData | 0 | 是 | int | 数据盘大小(GB)。0 表示无数据盘 |
| bandwidth | 0 | 是 | int | 带宽，不限填0 |
| imageId | 5 | 是 | int | 镜像编号。参见 [获取订购云服务器的镜像](获取订购云服务器的镜像.md) 中的实测镜像列表 |
| paymentCycle | 1 | 是 | int | 付款周期。1=月付, 2=季付, 3=半年付, 4=年付, 5=按小时 |
