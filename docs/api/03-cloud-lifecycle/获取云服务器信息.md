# 获取云服务器信息

## 简要描述

获取用户某台云服务器信息

## 请求URL

`https://api.zhaomu.com/cloud/:id`

## 请求方式

GET

## 路径变量

| 变量名 | 示例值 | 必选 | 类型 | 说明 |
|--------|--------|--------|--------|--------|
| id |  | 是 | int | 云服务器产品编号 |

## Header

| 字段名 | 示例值 | 必选 | 类型 | 说明 |
|--------|--------|--------|--------|--------|
| Authorization | Bearer <apikey> | 是 | string | API密钥 |

## 成功返回示例的参数说明

| 参数名 | 类型 | 说明 |
|--------|--------|--------|
| id | int | 云服务器编号 |
| ip | string | IP地址 |
| root | string | 用户名 |
| password | string | 密码 |
| cpu | int | CPU |
| ram | int | 内存（MB） |
| disk | int | 系统盘（GB） |
| diskData | int | 数据盘（GB） |
| diskMedia | string | 硬盘截止 |
| bandwidth | object | 带宽（Mbps） |
| traffic | int | 流量（GB/月） |
| image | string | 镜像名称 |
| renewPrice | string | 续费价格 |
| paymentCycle | string | 付款周期 |
| priceHour | number | 小时付价格 |
| price | int | 月付价格 |
| priceQuarter | int | 季付价格 |
| priceHalfYear | int | 半年付价格 |
| priceYear | int | 年付价格 |
| startTime | string | 开通时间 |
| endTime | string | 到期时间 |
| status | string | 状态 |
| note | object | 管理员备注 |
| noteUser | object | 用户备注 |
| isAutoRenew | string | 是否自动续费 |
| region_id | int | 可用区编号 |

## 备注

status 状态说明1 开通中2 运行中3 已关机4 已禁用5 准备中
