# 获取订购云服务器的镜像

## 简要描述

获取订购云服务器时，可选的镜像列表

## 请求URL

`https://api.zhaomu.com/image/product/:id`

## 请求方式

GET

## 路径变量

| 变量名 | 示例值 | 必选 | 类型 | 说明 |
|--------|--------|--------|--------|--------|
| id |  | 是 | int | 云服务器产品编号 |

## Header

| 字段名 | 示例值 | 必选 | 类型 | 说明 |
|--------|--------|--------|--------|--------|
| Authorization | Bearer <apikey> | 是 | string | API密钥 |

## 成功返回示例

```json
复制[{
  "id": 5,
  "name": "CentOS 7 64位",
  "type": "CentOS"
},{
  "id": 8,
  "name": "Ubuntu 18.04 64位",
  "type": "Ubuntu"
}]
```

## 成功返回示例的参数说明

| 参数名 | 类型 | 说明 |
|--------|--------|--------|
| id | int | 镜像编号 |
| name | string | 镜像名称 |
| type | string | 镜像类型 |

## 备注

无

## 实测镜像列表

**可用镜像类型：**

| 类型 | 示例镜像 |
|------|---------|
| CentOS | CentOS Stream 9, CentOS Stream 8, CentOS Linux 7.9 |
| Debian | Debian 12.8, Debian 11.1 |
| Ubuntu | Ubuntu Server 24.04, Ubuntu Server 22.04, Ubuntu Server 20.04 |
| Windows | Windows Server 2022, Windows Server 2019, Windows Server 2016 |
| AlmaLinux | AlmaLinux 9, AlmaLinux 8 |

注意：镜像可用性因区域和产品而异。Windows 镜像仅部分区域支持。
