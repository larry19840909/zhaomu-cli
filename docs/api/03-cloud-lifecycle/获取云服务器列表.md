# 获取云服务器列表

## 简要描述

获取用户全部云服务器列表

## 请求URL

`https://api.zhaomu.com/cloud`

## 请求方式

GET

## Header

| 字段名 | 示例值 | 必选 | 类型 | 说明 |
|--------|--------|--------|--------|--------|
| Authorization | Bearer <apikey> | 是 | string | API密钥 |

## 成功返回示例的参数说明

| 参数名 | 类型 | 说明 |
|--------|--------|--------|
| id | int | 云服务器编号（实例 ID）。用于 info/rebuild/renew/destroy 等操作 |
| ip | string | IP地址 |
| root | string | 用户名 |
| password | string | root 密码（list 接口通常不返回该字段，仅 info 接口返回） |
| cpu | int | vCPU 核数 |
| ram | int | 内存（MB） |
| disk | int | 系统盘（GB） |
| diskData | int | 数据盘（GB）。0 表示无数据盘 |
| diskMedia | string | 磁盘介质。实测值：SSD、NORMAL |
| bandwidth | int/null | 带宽（Mbps）。实测常为 null |
| traffic | int | 月度流量配额（GB） |
| image | string | 镜像名称。参见 [获取订购云服务器的镜像](获取订购云服务器的镜像.md) |
| renewPrice | number | 续费价格，单位元 |
| paymentCycle | int | 付款周期。1=月付, 2=季付, 3=半年付, 4=年付, 5=按小时 |
| priceHour | number/null | 按小时价格，单位元。null 表示不支持按小时 |
| price | number | 月付价格，单位元 |
| priceQuarter | number | 季付价格，单位元 |
| priceHalfYear | number | 半年付价格，单位元 |
| priceYear | number | 年付价格，单位元 |
| startTime | string | 开通时间 |
| endTime | string | 到期时间 |
| status | int | 实例状态。1=开通中, 2=运行中, 3=已关机, 4=已禁用, 5=准备中。参见本文档下方实测枚举值 |
| note | object | 管理员备注 |
| noteUser | object | 用户备注 |
| isAutoRenew | int | 自动续费。0=关闭, 1=开启 |
| region_id | int | 可用区编号。参见 [获取可用区列表](../01-regions/获取可用区列表.md) 中的实测枚举值 |

## 备注

status 状态说明1 开通中2 运行中3 已关机4 已禁用5 准备中

## 实测枚举值

**实例状态 (status) 枚举：**

| 值 | statusName | 说明 |
|----|------------|------|
| 1 | Provisioning | 开通中 |
| 2 | Running | 运行中 |
| 3 | Stopped | 已关机 |
| 4 | Disabled | 已禁用 |
| 5 | Preparing | 准备中 |
