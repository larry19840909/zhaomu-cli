# 获取云服务器产品信息

## 简要描述

获取某款云服务器产品信息

## 请求URL

`https://api.zhaomu.com/product/:id`

## 请求方式

GET

## 路径变量

| 变量名 | 示例值 | 必选 | 类型 | 说明 |
|--------|--------|--------|--------|--------|
| id |  | 是 | int | 云服务器产品编号 |

## Header

| 字段名 | 示例值 | 必选 | 类型 | 说明 |
|--------|--------|--------|--------|--------|
| Authorization | Bearer <apikey> | 是 | string | API密钥 |

## 成功返回示例

```json
复制{
  "id": 35,
  "cpu": 1,
  "ram": 1024,
  "disk": 25,
  "diskMax": 25,
  "diskData": 0,
  "diskDataMax": 40000,
  "diskMedia": "SSD",
  "bandwidth": null,
  "bandwidthMax": null,
  "traffic": 1000,
  "priceHour": 0.1,
  "price": 49,
  "priceQuarter": 147,
  "priceHalfYear": 294,
  "priceYear": 588,
  "tags": "",
  "outOfStock": 0,
  "noWindows": null,
  "region_id": 3
}
```

## 成功返回示例的参数说明

| 参数名 | 类型 | 说明 |
|--------|--------|--------|
| id | int | 产品编号 |
| cpu | int | CPU |
| ram | int | 内存（MB） |
| disk | int | 系统盘（GB） |
| diskMax | int | 系统盘最大值（GB） |
| diskData | int | 数据盘（GB） |
| diskDataMax | int | 数据盘最大值（GB） |
| diskMedia | string | 硬盘截止 |
| bandwidth | int | 带宽（Mbps） |
| bandwidthMax | int | 带宽最大值（Mbps） |
| traffic | int | 流量（GB/月） |
| priceHour | number | 小时付价格 |
| price | int | 月付价格 |
| priceQuarter | int | 季付价格 |
| priceHalfYear | int | 半年付价格 |
| priceYear | int | 年付价格 |
| minPaymentCycle | int | 最小付款周期 |
| tags | string | 标签 |
| outOfStock | boolean | 是否缺货 |
| noWindows | boolean | 是否不支持Windows |
| region_id | int | 可用区编号 |

## 备注

无
