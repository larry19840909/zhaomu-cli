# 获取功能参数比较

## 简要描述

获取某个可用区的功能参数比较

## 请求URL

`https://api.zhaomu.com/compare/region/:id`

## 请求方式

GET

## 路径变量

| 变量名 | 示例值 | 必选 | 类型 | 说明 |
|--------|--------|--------|--------|--------|
| id |  | 是 | string | 可用区编号。参见 [获取可用区列表](../01-regions/获取可用区列表.md) 中的实测枚举值 |

## Header

| 字段名 | 示例值 | 必选 | 类型 | 说明 |
|--------|--------|--------|--------|--------|
| Authorization | Bearer <apikey> | 是 | string | API密钥 |

## 成功返回示例

```json
复制[
  {
    "target_id": "1",
    "name": "实时开通",
    "explain": "支持"
  },
  {
    "target_id": "2",
    "name": "在线重启",
    "explain": "支持"
  },
  {
    "target_id": "3",
    "name": "在线关机",
    "explain": "支持"
  }
]
```

## 成功返回示例的参数说明

| 参数名 | 类型 | 说明 |
|--------|--------|--------|
| target_id | int | 功能参数编号，具体映射见本文档下方 [实测功能项枚举](#实测功能项枚举) 表（已含全部25个ID→名称→说明映射） |
| name | string | 功能参数名称 |
| explain | string | 功能支持状态。可能值：支持/不支持/提交工单/有效期内/显示/屏蔽80,443,25端口/6小时内开通/显示实际IP/原生IP |

## 备注

无
