# 获取功能参数比较

## 简要描述

获取某个可用区的功能参数比较

## 请求URL

`https://api.zhaomu.com/compare/region/:id`

## 请求方式

GET

## 路径变量

| 变量名 | 示例值 | 必选 | 类型 | 说明 |
|--------|--------|--------|--------|--------|
| id |  | 是 | string | 可用区编号 |

## Header

| 字段名 | 示例值 | 必选 | 类型 | 说明 |
|--------|--------|--------|--------|--------|
| Authorization | Bearer <apikey> | 是 | string | 无 |

## 成功返回示例

```json
复制[
  {
    "target_id": "1",
    "name": "实时开通",
    "explain": "支持"
  },
  {
    "target_id": "2",
    "name": "在线重启",
    "explain": "支持"
  },
  {
    "target_id": "3",
    "name": "在线关机",
    "explain": "支持"
  }
]
```

## 成功返回示例的参数说明

| 参数名 | 类型 | 说明 |
|--------|--------|--------|
| target_id | int | 功能参数编号 |
| name | string | 功能参数名称 |
| explain | string | 功能参数说明 |

## 备注

无
