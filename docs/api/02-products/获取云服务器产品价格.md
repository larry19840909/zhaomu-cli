# 获取云服务器产品价格

## 简要描述

获取某款云服务器的产品价格，支持获取自定义系统盘、数据盘、带宽的产品价格

## 请求URL

`https://api.zhaomu.com/product/price/:id`

## 请求方式

GET

## 路径变量

| 变量名 | 示例值 | 必选 | 类型 | 说明 |
|--------|--------|--------|--------|--------|
| id |  | 是 | int | 云服务器产品编号 |

## Header

| 字段名 | 示例值 | 必选 | 类型 | 说明 |
|--------|--------|--------|--------|--------|
| Authorization | Bearer <apikey> | 是 | string | API密钥 |

## 请求Query参数

| 参数名 | 示例值 | 必选 | 类型 | 说明 |
|--------|--------|--------|--------|--------|
| disk |  | 否 | int | 自定义系统盘大小(GB)，不传则使用默认规格 |
| diskData |  | 否 | int | 自定义数据盘大小(GB)，不传则使用默认规格 |
| bandwidth |  | 否 | int | 自定义带宽(Mbps)，不传则使用默认规格 |

## 成功返回示例

```json
复制{
  "1": 10,
  "2": 30,
  "3": 60,
  "4": 120,
  "5": 0.02
}
```

## 成功返回示例的参数说明

| 参数名 | 类型 | 说明 |
|--------|--------|--------|
| 1 | int | 月付价格（键为付款周期编号：1=月付） |
| 2 | int | 季付价格（键为付款周期编号：2=季付） |
| 3 | int | 半年付价格（键为付款周期编号：3=半年付） |
| 4 | int | 年付价格（键为付款周期编号：4=年付） |
| 5 | number | 按小时价格（键为付款周期编号：5=按小时，仅部分产品支持） |

## 备注

1、如果不传系统盘、数据盘、带宽参数，则获取的是默认规格的产品价格，和“获取云服务器产品信息”接口的数据一致。2、部分产品不支持按小时支付，则不显示小时价格；部分产品最小付款周期非月付，则不显示月付价格。
