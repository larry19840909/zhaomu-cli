# 获取云服务器产品列表

## 简要描述

获取某个可用区下的云服务器产品列表

## 请求URL

`https://api.zhaomu.com/product/region/:id`

## 请求方式

GET

## 路径变量

| 变量名 | 示例值 | 必选 | 类型 | 说明 |
|--------|--------|--------|--------|--------|
| id |  | 是 | string | 可用区编号。参见 [获取可用区列表](../01-regions/获取可用区列表.md) 中的实测枚举值 |

## Header

| 字段名 | 示例值 | 必选 | 类型 | 说明 |
|--------|--------|--------|--------|--------|
| Authorization | Bearer <apikey> | 是 | string | API密钥 |

## 成功返回示例的参数说明

| 参数名 | 类型 | 说明 |
|--------|--------|--------|
| id | int | 产品编号。用于订购、询价等操作 |
| cpu | int | vCPU 核数。实测范围：1-24 核 |
| ram | int | 内存，单位 MB。实测范围：1024-393216（1G-384G） |
| disk | int | 系统盘，单位 GB。实测范围：10-2048G |
| diskMax | int | 系统盘最大值（GB） |
| diskData | int | 数据盘（GB） |
| diskDataMax | int | 数据盘最大值（GB） |
| diskMedia | string | 磁盘介质。实测值：SSD、NORMAL |
| bandwidth | int/null | 带宽，单位 Mbps。实测常为 null |
| bandwidthMax | int/null | 带宽最大值（Mbps）。实测常为 null |
| traffic | int/null | 月度流量配额，单位 GB。null 表示不限流量。实测范围：1000-15000G |
| priceHour | number/null | 按小时价格，单位元。null 表示不支持按小时 |
| price | number | 月付价格，单位元 |
| priceQuarter | number | 季付价格，单位元 |
| priceHalfYear | number | 半年付价格，单位元 |
| priceYear | number | 年付价格，单位元 |
| tags | string | 标签。实测值：""（空）、"原生IP"、"支持Windows" |
| outOfStock | int | 缺货状态。0=有货，1=缺货 |
| noWindows | int/null | 是否不支持 Windows。null=支持，1=不支持 |
| region_id | int | 可用区编号。参见 [获取可用区列表](../01-regions/获取可用区列表.md) 中的实测枚举值 |
