# 获取可用区信息

## 简要描述

获取某个可用区的信息

## 请求URL

`https://api.zhaomu.com/region/:id`

## 请求方式

GET

## 路径变量

| 变量名 | 示例值 | 必选 | 类型 | 说明 |
|--------|--------|--------|--------|--------|
| id | 3 | 是 | int | 可用区编号。参见 [获取可用区列表](获取可用区列表.md) 中的实测枚举值 |

## Header

| 字段名 | 示例值 | 必选 | 类型 | 说明 |
|--------|--------|--------|--------|--------|
| Authorization | Bearer <apikey> | 是 | string | API密钥 |

## 成功返回示例

```json
复制{
  "id": 3,
  "continent": "北美洲",
  "continentEn": "north-america",
  "country": "美国",
  "countryEn": "us",
  "area": "美西",
  "areaEn": "us-west",
  "province": "加州",
  "provinceEn": "california",
  "city": "洛杉矶",
  "cityEn": "los-angeles",
  "zone": "V"
}
```

## 成功返回示例的参数说明

| 参数名 | 类型 | 说明 |
|--------|--------|--------|
| id | int | 可用区编号。参见 [获取可用区列表](获取可用区列表.md) 中的实测枚举值 |
| continent | string | 大洲 |
| continentEn | string | 大洲英文 |
| country | string | 国家 |
| countryEn | string | 国家英文 |
| area | string | 地区 |
| areaEn | string | 地区英文 |
| province | string | 省份 |
| provinceEn | string | 省份英文 |
| city | string | 城市 |
| cityEn | string | 城市英文 |
| zone | string | 线路/可用区名称。参见 [获取可用区列表](获取可用区列表.md) 中的 Zone 枚举值 |

## 备注

无
