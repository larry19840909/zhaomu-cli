# 获取可用区列表

## 简要描述

获取全部可用区列表

## 请求URL

`https://api.zhaomu.com/region`

## 请求方式

GET

## Header

| 字段名 | 示例值 | 必选 | 类型 | 说明 |
|--------|--------|--------|--------|--------|
| Authorization | Bearer <apikey> | 是 | string | API密钥 |

## 成功返回示例的参数说明

| 参数名 | 类型 | 说明 |
|--------|--------|--------|
| id | int | 可用区编号。用于产品查询等操作 |
| continent | string | 大洲 |
| continentEn | string | 大洲英文 |
| country | string | 国家 |
| countryEn | string | 国家英文 |
| area | string | 地区 |
| areaEn | string | 地区英文 |
| province | string | 省份 |
| provinceEn | string | 省份英文 |
| city | string | 城市 |
| cityEn | string | 城市英文 |
| zone | string | 线路/可用区名称。参见本文档下方 Zone 枚举值 |
